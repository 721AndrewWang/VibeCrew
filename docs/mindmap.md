## 第一性原理：安全、可解释、可恢复
- 每个审批说明为什么要问（`7ec74c7`）
- 崩溃不丢活：进度每 3 秒落盘，中断的一轮保留（`2fcc337`）
- 数据格式版本号和迁移，迁移前自动备份
- 接口入口校验参数（zod）（`aafb2c6`）
- 沙盒：命令关进 bubblewrap，网络只到白名单（`b550fb2` `5a85d59`）
  - 实测发现：不在名单上的主机原来只是「询问」，改成直接拒绝
  - 沙盒里连本机要加 `env -u no_proxy -u NO_PROXY`

## 角色与成本
- 角色绑定模型档位、只能修改的路径、每月预算（`bf147f8`）
- 每轮轨迹：读 Claude Code 自己的记录，看每次调用的 token（`42f179c`）
  - 第一次真用就抓到解析错误：并行工具调用被算成多次（`ab18bad`）
- 每轮只发新内容：长消息变摘要，`chat_history` 查全文（`8a87253`）
- 验收、审查角色每轮新会话：Probe 一轮从 $0.32 降到 $0.19（`94d3e4b`）
- 发现：钱主要花在重读上下文，不是写输出
- 会话超过 60k token 就换新会话，带上最近 12 条消息（`1978cce`）
  - 用绝对 token 数：窗口有 100 万，按百分比永远不会触发
